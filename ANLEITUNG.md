# Bilderrahmen-Swiper – Kurzanleitung

Aus vielen Fotos die besten für deinen digitalen Bilderrahmen wählen:
**grüner Knopf oder → = behalten, roter Knopf oder ← = weg.**
Behaltene Fotos werden automatisch auf das Format deines Bilderrahmens gebracht und
sortiert in einen neuen Ordner kopiert. **Deine Originale werden nie verändert.**

## Starten

1. `Bilderrahmen-Swiper.exe` herunterladen und doppelklicken. Keine Installation nötig.
2. Beim ersten Start warnt Windows evtl. „Der Computer wurde durch Windows geschützt“.
   Das liegt nur daran, dass das Programm nicht signiert ist:
   **„Weitere Informationen“ → „Trotzdem ausführen“.**
3. Beim ersten Durchgehen zeigt eine kurze Einführung die wichtigsten Handgriffe.

## In 4 Schritten zum fertigen Rahmen

1. **Rahmen einstellen:** Das **Zahnrad** (oben rechts oder unter dem Start-Knopf) öffnet die
   Einstellungen. Sie haben drei Seiten: *Rahmen*, *Bild* und *App*. Unter *Rahmen* die Auflösung deines Rahmens wählen (z. B. *10 Zoll · 1280 × 800*)
   oder eigene eintippen. Format und Größe passen sich dann automatisch an.
2. **Ordner wählen:** Ordner aus dem Explorer auf die Fläche **„Ordner hierher ziehen“**
   ziehen oder darauf klicken. Die Fläche leuchtet auf, sobald du etwas darüber hältst, und
   sagt dir, wenn es kein Ordner ist; Ordner ohne Fotos werden nicht übernommen. Klick = an-/abwählen,
   **Doppelklick = direkt diesen Ordner starten**. **Rechte Maustaste gedrückt halten** zeigt
   die Fotos eines Ordners groß, das Mausrad blättert. Ein **kurzer Rechtsklick** (oder **⋯**
   an der Kachel) öffnet das Ordner-Menü: **Aussortierte nochmal zeigen**, **Ganz von vorn**
   (behaltene Bilder bleiben im Zielordner) und **Aus der Liste entfernen**.
   Der **Pfeil rechts am Start-Knopf** öffnet den **Zeitraum**: nur Fotos aus einem Jahr oder
   einem eigenen Zeitraum, z. B. *Juni – August 2023*.
3. **Loslegen:** Im selben Pfeil-Menü wählst du den Ablauf: **Alles in einem Durchgang** oder
   **Erst sortieren, dann Feinschliff** (siehe unten). Die Fotos kommen nach Aufnahmedatum
   sortiert. Ist ein Ordner durch, zeigt eine Abschlussseite, wie viele Fotos du behalten und
   aussortiert hast und wie lange es gedauert hat, und schlägt den nächsten Ordner vor. Das **Haus** oben links bringt dich jederzeit zum
   Startbildschirm; dein Stand steht dann unter **„Weitermachen“**.
4. **Auf den Rahmen bringen:** Sind alle Ordner durch, kopiert
   **„Auf USB-Stick / SD-Karte kopieren“** alles mit einem Klick. Dort wählst du auch die
   **Reihenfolge auf dem Rahmen**: *nach Datum*, *zufällig* oder *nach Ordner*. Bilder, die
   schon drauf sind, werden übersprungen.

Die Bilder liegen im Zielordner (Standard: `Bilder\Bilderrahmen`) in **`Quer`** und
**`Hochkant`**, z. B. `2024-07-15_143012_IMG_1234.jpg`.

## Bedienung

Oben in der Mitte sitzt eine kompakte Leiste: das **Haus** (zum Startbildschirm, speichert
deinen Stand), das Zahnrad für die **Einstellungen**, der Umschalter **Quer / Hochkant**,
Ordner und Fortschritt, die Zahl der behaltenen Bilder und ganz rechts das kleine
**Tastatur-Symbol** mit allen Kürzeln (oder **?** bzw. **F1**).

Unten schwebt die Leiste fürs Bild, sortiert nach Wichtigkeit: in der Mitte die beiden großen
Knöpfe **Weg** (rot) und **Behalten** (grün), links **Zurück**, rechts die Werkzeuge
(**Drehen**, **Format**, **Vorschau**, **Ganz**, **Text**). Der kleine **Pfeil** an Drehen, Ganz
und Text öffnet jeweils die Feineinstellungen. Jeder Knopf zeigt klein die Taste,
die gerade dafür eingestellt ist, auch wenn du sie geändert hast.

| Aktion | Maus | Taste (änderbar) |
|---|---|---|
| Behalten | **Behalten** | **→** oder D |
| Weg | **Weg** | **←** oder A |
| Rückgängig (auch nach Neustart) | **Zurück** oder „Rückgängig“ in der Meldung | **Rücktaste** oder Strg+Z |
| Bild drehen | **Drehen** | **R**, andersherum **L** |
| Quer ↔ Hochkant | **Format** oder oben auf das Format klicken | **H** |
| Ganzes Foto statt zuschneiden | **Ganz** (Pfeil: Rand wählen) | **F** |
| Begradigen: Vorschlag übernehmen | Pfeil an **Drehen** | **B** |
| Horizont selbst festlegen | **Strg** halten und am Horizont entlang ziehen | – |
| Automatisch verbessern | Pfeil an **Drehen** | **E** |
| Hilfslinien wechseln | – | **O**, drehen mit **Umschalt+O** |
| Vorschau wie auf dem Rahmen | **Vorschau** | **V** |
| Text aufs Bild an / aus | **Text** | **T** |
| Textfeld (Ort, Notiz, Stil) | kleiner Pfeil an **Text** | – |
| Zum Startbildschirm, später weitermachen | **Haus** oben links | – |
| Ausschnitt verschieben | den hellen Rahmen mit der Maus ziehen | – |
| Ausschnitt größer / kleiner | an einer **Ecke** des Rahmens ziehen | – |
| Hinein-/Herauszoomen | **Mausrad** oder zwei Finger am Touchpad | + / − |
| Ausschnitt zurücksetzen | Doppelklick aufs Bild | 0 |
| Durch alle Fotos blättern | Bilderband unten mit der Maus ziehen oder Mausrad | – |
| Foto groß ansehen | rechte Maustaste auf Bilderband, Galerie oder Ordner halten | – |
| Serie vergleichen | gelber Hinweis „Serie“ | **S** |
| Behaltene ansehen, Diashow | grünes ♥ in der oberen Leiste, dort **Diashow** | **G** |
| Behaltenes Bild nachbearbeiten | in der Galerie **Bearbeiten** oder Doppelklick | – |
| Einstellungen | Zahnrad oben | Strg+B |
| Schrift größer / kleiner | – | **Strg +** / **Strg −** (Strg 0 = normal) |
| Vollbild | – | F11 |
| Alle Tastenkürzel | Tastatur-Symbol oben | **?** oder F1 |

**Tasten ändern:** Einstellungen → *App* → *Tasten*. Auf ein Feld klicken und die
neue Taste drücken. Rechtsklick leert ein Feld.

## Zuschneiden

Das Foto liegt ganz auf der Karte, der **helle Rahmen** zeigt, was auf den Bilderrahmen kommt.
Zieh den Rahmen mit der Maus an die richtige Stelle. An den **Ecken** (kleine weiße Winkel)
ziehst du ihn größer oder kleiner, das Seitenverhältnis bleibt dabei gleich. Mausrad und
zwei Finger am Touchpad zoomen ebenfalls. **Doppelklick** setzt zurück.

Neue Fotos bekommen gleich einen **schlauen Ausschnitt**: Das Programm legt den Rahmen auf
den Teil mit Menschen und Details statt stur in die Mitte. Abschalten unter Einstellungen →
*Bild* → *Ausschnitt*.

## Erst sortieren, dann Feinschliff

Wählst du auf dem Startbildschirm **Erst sortieren, dann Feinschliff**, zeigt der erste
Durchgang nur das Foto mit **Zurück**, **Weg**, **Behalten** und **Drehen**. So gehst du große
Ordner schnell durch. Ist der Ordner fertig, startet **„Feinschliff: … zuschneiden“** einen
zweiten Durchgang nur über die gerade behaltenen Fotos, mit allen Werkzeugen. **Behalten**
speichert und geht zum nächsten Foto, **Weg** nimmt es doch noch heraus, **Esc** beendet den
Feinschliff (die übrigen Fotos bleiben dann im schnellen Zuschnitt). Mit **„Später“** kannst du
ihn auch auslassen und erst den nächsten Ordner machen.

## Bilderband

Unter dem Foto liegt das Bilderband mit allen Fotos des Ordners. Mit gedrückter Maus ziehen
(oder Mausrad) blättert, ein Klick springt zu einem Foto. Ein **grüner Punkt** heißt behalten,
ein **roter** weg.

## Vorschau und Diashow

**V** zeigt das aktuelle Foto bildschirmfüllend so, wie es auf dem Rahmen erscheint: mit
Zuschnitt, Auflösung und Text. In der Galerie der behaltenen Bilder startet **Diashow** alle
Bilder nacheinander (alle 8 Sekunden). **Leertaste** pausiert, **← →** blättern, **Esc** schließt.

## Ganzes Foto statt Abschneiden

Mit **F** wird ein Foto nicht zugeschnitten, sondern **ganz** auf den Rahmen gelegt. Ideal für
Hochkant-Fotos auf einem Quer-Rahmen: Ein Hochkant-Foto wird dabei automatisch auf **Quer**
gestellt und landet im Ordner `Quer`. Mit **H** kannst du das wie gewohnt umstellen.

- **Größe und Lage:** Das Foto mit der Maus verschieben, an den Ecken größer oder kleiner
  ziehen, Mausrad zoomt. Kleiner lässt mehr Rand, größer schneidet an. Doppelklick setzt zurück.
- **Rand:** Der Pfeil an **Ganz** wählt *Unscharf* (mit Regler für die Stärke), *Fotofarbe*,
  *Schwarz* oder *Weiß*. **Als Standard** übernimmt die Wahl für alle neuen Bilder (auch unter
  Einstellungen → *Bild*).

## Hilfslinien

**O** wechselt die Hilfslinien beim Zuschnitt wie in Lightroom: *Drittel*, *Goldener Schnitt*,
*Raster*, *Diagonale*, *Goldenes Dreieck*, *Goldene Spirale* und *aus*. **Umschalt+O** dreht bzw.
spiegelt Dreieck und Spirale.

## Begradigen und Licht

Der Pfeil an **Drehen** öffnet ein kleines Feld:

- **Begradigen** um bis zu ±10°. Findet das Programm einen schiefen Horizont, steht dort ein
  **Vorschlag** (Taste **B**). Selbst festlegen: **Strg** gedrückt halten und mit der linken
  Maustaste eine Linie am Horizont (oder an einer Hauswand) entlang ziehen.
- **Licht:** *Automatisch verbessern* (Taste **E**) sowie **Helligkeit** und **Kontrast**.

## Doppelte Fotos

Liegt dasselbe Foto in zwei Ordnern (auch umbenannt oder verkleinert), erscheint ein gelber
Hinweis **„Schon behalten“** mit kleinem Vorschaubild. Ein Klick zeigt das frühere Bild groß.
Erkannt wird am Bildinhalt und an der Aufnahmezeit, nicht am Dateinamen.

## Ähnliche Fotos vergleichen

Mehrere fast gleiche Fotos hintereinander (Serie oder gleiches Motiv) bekommen einen gelben
Hinweis **„Serie“**. **S** (oder ein Klick darauf) zeigt sie nebeneinander, du markierst die
besten und bestätigst mit **Enter**. Erkannt wird an der Aufnahmezeit und am Bildinhalt.

## Behaltene nachbearbeiten

In der Galerie (grünes ♥) hat jedes Bild **Bearbeiten**. Du landest in der gewohnten Ansicht
mit allen Werkzeugen (Zuschnitt, Ganz, Text, Begradigen, Licht). **Behalten** speichert das
Bild neu und ersetzt das alte, **Weg** nimmt es aus den Behaltenen, **Esc** bricht ab.
Löschst du Bilder direkt im Zielordner, verschwinden sie auch hier und gelten als aussortiert.

## Mehrere Rahmen

Einstellungen → *Rahmen* → **+ Weiterer Rahmen**, z. B. für die Großeltern. Jeder
Rahmen hat sein eigenes Format und seinen eigenen Zielordner (`Bilderrahmen <Name>`), und
dasselbe Foto kann für jeden Rahmen behalten werden. Umschalten per Klick auf den Namen.

## Text aufs Bild

**T** (oder ein Klick auf **Text**) schaltet den Text an und aus. Der kleine **Pfeil** an
**Text** öffnet links ein Feld, ohne das Foto zu verschieben:

- **Ort** gilt für den ganzen Ordner (vorgeschlagen wird der Ordnername), bis du ihn änderst.
- **Notiz** gilt nur für dieses eine Bild.
- **Datum**, **Ort** und **Notiz** lassen sich einzeln ein- und ausschalten.
- **Stil bearbeiten …** öffnet den Stil-Editor.

### Stil-Editor

Links stehen die mitgelieferten Stile (*Dezent*, *Schatten*, *Dunkles Band*, *Glas*,
*Klassisch*, *Handschrift*, *Plakativ*) und deine eigenen. In der Mitte siehst du das aktuelle
Foto genau so, wie es gespeichert wird. Rechts stellst du alles ein:

- **Schrift:** Modern, Klassisch, Handschrift oder Plakativ, auf Wunsch in Großbuchstaben
- **Größe**, **Farbe** (Vorschläge oder eigene Farbe) und **Deckkraft**
- **Hintergrund:** ohne, Schatten, dunkles Band oder Glas (weichgezeichnetes Feld)
- **Position:** neun Stellen von oben links bis unten rechts, dazu der Abstand zum Rand

**Als eigenen Stil speichern** legt den Stil mit Namen in die Liste. Mit den beiden Symbolen
daneben **exportierst** du einen Stil als Datei (`.textstil`) bzw. **importierst** ihn, etwa
auf einem anderen PC. **Nur für „Ordner“** merkt sich den Stil nur für den Ordner des
aktuellen Fotos; alle anderen Ordner behalten den allgemeinen Stil.

## Programm aktualisieren

Gibt es eine neue Version, erscheint oben rechts auf dem Startbildschirm
**„Version X installieren“**. Ein Klick lädt sie herunter, danach startet
**„Neu starten mit X“** das Programm neu. Dein Stand bleibt erhalten. Klappt das nicht (etwa
weil die .exe in einem geschützten Ordner liegt), öffnet derselbe Knopf die Download-Seite.

## Gut zu wissen

- **Weitermachen:** Das **Haus** oben links merkt sich Ordner, Bild, Zeitraum und
  Einstellungen der laufenden Auswahl. Auf dem Startbildschirm steht sie unter
  **„Weitermachen“**: **Weiter** macht genau dort weiter, der Stift benennt sie um, der
  Papierkorb entfernt sie aus dem Verlauf (behaltene Bilder bleiben). Ist eine Auswahl ganz
  durch, verschwindet sie von selbst. Einfach schließen geht auch, **Rückgängig**
  funktioniert nach einem Neustart weiterhin.
- **Zeitraum:** Die Aufnahmedaten werden einmal im Hintergrund gelesen und gemerkt. Solange
  das läuft, zählen Fotos ohne bekanntes Datum vorerst mit.
- **Farben:** Einstellungen → *App*: *wie Windows*, *Hell*, *Dunkel*, *Sand*, *Salbei*
  oder *Nachtblau*. Der Hintergrund ist immer eine ruhige, volle Farbe.
- **Formate:** JPG, PNG, WebP, BMP, TIFF, GIF. **iPhone-Fotos (HEIC)** funktionieren, wenn
  in Windows die kostenlosen *HEIF-Bilderweiterungen* (und ggf. *HEVC-Videoerweiterungen*)
  aus dem Microsoft Store installiert sind.
- Handy-Fotos werden automatisch richtig herum gedreht.
- Einstellungen gelten für alle Bilder, die du **ab jetzt** behältst.
- **Sicherung:** Dein Fortschritt liegt im Zielordner und zusätzlich unter
  `%LOCALAPPDATA%\Bilderrahmen-Swiper\sicherung`. Geht die Datei im Zielordner verloren,
  wird sie von dort wiederhergestellt.
- **Falls etwas schiefgeht:** Unten links in den Einstellungen steht die Version und der Link
  **„Fehlerprotokoll“**. Die Datei
  `%LOCALAPPDATA%\Bilderrahmen-Swiper\protokoll.txt` hilft bei der Fehlersuche.
  Dort liegen auch die zwischengespeicherten Vorschaubilder (höchstens etwa 200 MB).
